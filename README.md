# 旋律草稿 · TetoMelody v1.0

为重音Teto UTAU日语音源做的原生 iPad 旋律编辑器。导入音源后，编辑、歌声合成、保存和 WAV 导出都在设备上完成。

## 运行

需要安装了 Xcode 16或更高版本的 Mac，支持 iPadOS 17及以上。打开 `TetoMelody.xcodeproj`，选中 `TetoMelody` scheme 和一台 iPad 模拟器即可运行。安装到 iPad 时，在目标的 Signing & Capabilities 中选择团队，并选择已启用开发者模式的设备。Xcode 首次构建会获取固定版本的 ZIPFoundation、MeCab／IPADic 和 Yams。

```sh
xcodebuild -project TetoMelody.xcodeproj -scheme TetoMelody \
  -destination 'generic/platform=iOS Simulator' CODE_SIGNING_ALLOWED=NO build
```

## 工程管理

启动后进入欢迎页。可命名并新建空白工程，从「文件」打开 .tetomelody，也可点「打开示例」载入16小节双轨工程。编辑过的工程会自动保存在本机，之后可从「最近工程」继续。旧版保存的旋律会出现在「上次编辑的旋律」。

编辑页的「保存」在第一次使用时会让你选文件位置，已打开或已保存的工程可以通过「保存」更新原文件。「工程」菜单提供「另存为」，可以选新位置或文件名。`.tetomelody` 保存工程长度、循环区间、共享速度、各轨音量、静音、独奏、音符、歌词和演唱调校。旧工程的节拍位置会自动迁移到480 PPQN。换设备打开后需要在该设备导入音源。旧版单轨工程会自动迁入「主唱」轨。

## 欢迎页插画

个人构建使用[重音Teto官网配布的角色插画](https://kasaneteto.jp/illust-logo/)。Xcode 读取本地的 `App/Assets.xcassets/TetoWelcomeIllustration.imageset`，资源按[角色使用条款](https://kasaneteto.jp/guideline/character.html)用于个人非商用构建。图片著作权标注为重音テト © 線／小山乃舞世／TWINDRILL。从 Git 克隆后，个人构建可运行 `python3 scripts/fetch_teto_art.py`，从官网获取同一张插画、校验原图并生成本地 Xcode 资源。如果 `LocalArtwork/OfficialTetoUTAU.png` 已有官网原图，脚本会优先复用。在 macOS 使用系统的 sips 缩放，其他平台使用 Pillow。

## 使用

1. 在重音Teto官网选择「通常音源 単独音」，将 `TETO-tandoku-100619.zip` 保存到 iPad 的「文件」。在 App 中点「导入音源 ZIP」。[官方音源](https://kasaneteto.jp/utau/)
2. 点工具栏的小节数可追加小节或设置工程长度，范围1至128小节。双指缩放时间轴，用滑块或「移动」工具横向浏览。音高视图和底部钢琴键盘可分别切换八度。画笔添加音符，拖动音符可修改起拍和音高，拖右端修改时值。
3. 用「框选」选中多音符，打开音符编辑菜单复制、移调或删除。点时间尺移动录入光标，再粘贴到当前音轨，也可先切换到和声轨。网格吸附支持1/16、1/8和1/4。
4. 点时间尺设定试听起点，拖动时间尺以小节为单位设置循环。切换「循环」可试听选中区间或整曲。分轨和混音 WAV 自第1小节起对齐。
5. 左侧可新增最多8条人声音轨，支持静音、独奏、重命名、复制、重排和音量。删除轨道前会确认，可撤销。点「导出 WAV」导出混音或当前轨的44.1 kHz、16位单声道音频。
6. 选中单个音符后点「调校」，可接唱前一音符、改变滑音时间和发音起点、画音高曲线，并调整颤音深度和速率。底部钢琴键盘默认收起，展开可切换试听或录入。编辑会自动保存，支持⌘Z和⇧⌘Z。

### 批量录入日语歌词

在当前音轨创建音符后，点编辑工具栏的「批量歌词」。输入「桜が咲く。」并点「转换为假名」，预览会把`さくらがさく`对应到6个音符。假名可直接修改，适合校对人名、生僻词和多音字。可从选中的音符、录入光标或音轨开头写入，依据音符的起拍顺序分配。音符不足时先补音符，写入后可以一次撤销。

汉字转假名使用随 App 打包的 MeCab 和 IPADic，安装后可离线处理。标点不占音符，`きゃ`占1个音符，`ー`用前一个发音的元音延长1个音符。重音单独音缺少`っ`采样时，该音符留出促音的闭塞时长。[组件源码](https://github.com/shinjukunian/Mecab-Swift/tree/0.8.0) · [词典与组件许可](App/JapaneseLyricsNotices.txt)

## 乐谱互通

欢迎页和「工程」菜单可导入 MIDI（类型0／1）、UST 或 USTX。重叠音符会在可用音轨范围内拆成单声部，导入结果会提示格式降级。「导出乐谱」可导出全部音轨为 MIDI 或 USTX，UST 导出当前音轨。

当前工程使用4/4拍和单一速度。其它拍号、变速、伴奏片段和各合成器专用表达参数需以导入提示为准。编辑器的完整调校和循环请保存在`.tetomelody`中。导入渐进检查可用同一首16小节工程在三个格式中各导出一次，再逐一打开核对音轨和音符。

## iPad 真机验收

| 项目 | 在 iPad 上检查 |
| --- | --- |
| 长时间轴 | 打开16小节双轨示例，缩放并横移到末尾，框选旋律，复制到另一轨、移调并撤销。拖时间尺圈出4小节，确认只循环该区间。 |
| 歌声调校 | 对相邻的音符启用连音。改变滑音、颤音、音高偏移或发音早晚，重新试听对应小节。 |
| 多轨 | 重命名、复制和调序，降低和声音量，分别试听混音和单轨。两份分轨 WAV 应与混音时长一致。 |
| 工程与互通 | 批量输入日语歌词，重新打开已保存的工程。将示例导出为 MIDI、UST、USTX，再导入核对时间位置、歌词和轨道。 |
| 性能 | 记录设备型号、iPadOS 版本、首次合成耗时和拖动时是否掉帧。iPad 真机帧率需在设备上实测。 |

## 实现与范围

- App 使用 SwiftUI 和 AVFoundation。ZIP 导入读取日文旧编码的 `oto.ini` 与匹配的 WAV，音源保存在设备的应用目录。
- 合成由独立的 C++17 核心完成。根据 `oto.ini` 裁剪和对齐采样，保留固定段，估计发声周期后，按目标音高重采样并调整时长。适配日语单独音，音高曲线驱动发声周期的相位，连音组共用一次发声。渲染支持直接生成循环区间和对齐的分轨 WAV。
- 仓库内不附带原始音源、角色素材或渲染样音。使用音源须遵守[官方音源条款](https://kasaneteto.jp/guideline/voice.html)。

## 合成核心检查

可在有 C++17编译器的环境中验证合成器。测试使用生成的波形，覆盖变调、短样本、音高曲线和区间裁剪，不需要下载音源。

```sh
mkdir -p build
c++ -std=c++17 -O2 -Wall -Wextra -Werror -INative Native/TetoDSP.cpp Tests/TetoDSPTests.cpp -o build/teto-dsp-tests
./build/teto-dsp-tests
```
